# 素材自动采集与回填

## 何时执行

用户要求完整机会分析或素材分析时，素材采集属于任务本身。以下任一情况必须执行本流程：

- `素材（AI 自动拉）`为空
- 现有素材没有覆盖目标国家 × 三级类目
- 素材样本缺少稳定链接、排名或分析所需字段
- 用户要求按新的国家、类目或周期重新拉取

不得把空白素材 Sheet 当成业务方缺数，也不得只根据爆品标题推测素材打法。

## 采集粒度

1. 从类目映射和细分赛道 Sheet 取得需要分析的三级类目，不凭名称猜路径
2. 多国家任务按`国家 × 三级类目`逐个采集；单一国家任务仍须按`国家 × 三级类目`分开
3. 平台需要先选区域时，先选择任务对应区域，再选择国家与完整类目路径
4. 默认每个组合采集 Top100；页面为每页20条时读取5页。用户或平台另有明确上限时按真实上限执行并记录
5. 不用大类混合样本替代三级类目样本，不把一个国家的素材外推到另一个国家

## 浏览器与导出

- 优先使用营销参谋/营销顾问的 Creative Insight 页面和用户现有登录态
- 开始前确认筛选器显示的区域、国家、类目路径和周期
- 若平台支持跨页全选，完成目标组合的全部页面选择后再导出
- 若导出异常，允许逐页读取或下载后合并，但必须核对目标条数、页码连续性和筛选条件
- 下载属于原始数据采集；写入在线表格前确认任务已授权该目标表。用户已明确要求完整报告并指定回填表时，不重复询问
- 页面未登录、浏览器能力未开启或权限受限时，明确提示用户完成对应操作；恢复后从当前组合继续，不重新抓已验证组合

## 原始明细字段

尽量保留平台可提供的原始字段，至少包括：

- 国家、一级/二级/三级类目
- 排名、素材标题或脚本摘要
- 视频链接或稳定素材 ID
- GMV 区间、广告消耗、CPM、CTR、CVR、CPA、ROAS（平台提供多少保留多少，不补造）
- 数据周期、来源页面、校验状态、剔除原因、是否纳入总结

同一字段缺失时留空，不用0代替。

## 去重与质检

1. 优先按稳定素材 ID 去重，缺少 ID 时使用规范化视频链接
2. 去掉跨页重复、同链接重复和明显失效链接
3. 核对素材画面/标题与国家、三级类目是否一致；错挂素材保留质检记录但不纳入总结
4. 同一素材出现在多个组合时，仅在确实服务不同国家或三级类目时分别保留，并记录组合来源
5. 每个组合记录抓取数、有效数、重复数和疑似错挂数供质检使用，但前台报告不展示“有效 xx/100”
6. 任一重点组合样本严重不足或 Top3 链接失效时，先补抓；仍无法补齐再向用户说明

## 洞察与回填

先把去重后的原始数据写入`素材（AI 自动拉）`或对应的分国三级类目明细 Sheet，再生成`素材洞察（AI 自动拉）`。每个国家 × 三级类目一行，至少包含：

- 内容主轴
- 前三秒开场
- 中段证明方式
- 高频卖点
- 目标人群与使用场景
- 转化收口
- Top3 爆款素材名称与三个独立链接
- 一条能指导创作或投放的行动结论

素材洞察必须建立在实际采集素材上。报告正文先讲该国家和三级类目的爆品，再讲素材如何销售这些产品。

## 完成校验

- 所有目标国家 × 三级类目都有对应原始素材或明确的无数据记录
- Top3 链接可访问且与类目相符
- 原始明细、汇总洞察和报告中的类目命名一致
- 没有把质检过程指标当成前台商业结论
- 未因导出失败、页面难操作或工具差异跳过任何目标组合
