# 飞书文档与文字规范

## 推荐文档结构

每个业务大类使用同一层级，方便横向比较：

1. 大类结论摘要
2. 国家选择
3. 竞争格局
4. 细分类目与价格带
5. 分国家爆品与产品线
6. 分国家、分三级类目素材打法
7. 经营优先级与行动建议

存在两个以上业务大类时，每个大类独立走完完整链路，不把多个类目的店铺、爆品或素材混写。

## 呈现形式

- 以飞书文档为主交付，图表与图片承担数据呈现，正文承担解释与决策
- 先放结论，再放支持它的图表
- 商品图放在对应国家、三级类目和产品线下
- 素材链接放在独立列，每个国家 × 三级类目保留 Top3
- 来源网址紧跟对应图表或事实，不集中丢到文末
- 正文不复制大段数据表，只展示必要的排名、份额和代表性数值

## 结论写法

每个段落都按国家分点，一国一条核心判断。句式优先：

`国家：优先级/机会判断，依据1、依据2、依据3；对应动作`

示例：

`泰国：第一优先级，市场规模大、增长快且 TR 高；优先承接成熟品线与品牌型供给`

规则：

- 标题和首句必须给结论，不以“从图中可以看出”开头
- 数字只保留能证明判断的 1–3 个
- 多用逗号、分号和短语，少用句号切碎逻辑
- 不写“机会巨大、未来可期、赋能增长”等套话
- 不把事实、推断和建议混成一句；证据不足时明确写“观察项”或“需验证”
- 不重复图里已经清楚呈现的全部数值
- 国家名称、三级类目、价格带和产品线命名全文一致

## 全文自检

交付前逐项确认：

- 每个国家结论独立分点，且能直接指导优先级
- 所有标题与正文的国家/类目一致
- CR3 店铺配有正确主力商品图与背景来源
- 价格带图例显示真实区间
- 每个机会三级类目有更细的场景 × 人群产品线
- 每条产品线有足够商品例子，不使用孤例代表总体
- 爆品在前、素材在后，且都放在对应国家
- 素材按国家 × 三级类目总结并附 Top3 链接
- 不展示无决策价值的“有效 xx/100”等过程数据
- 图表完整、标签可读、来源可追溯
- 删除不改变判断的重复句和解释性废话
